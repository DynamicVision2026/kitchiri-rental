## How to clear a group

1. Pull the primary text named under **Where**.
2. Answer every question under **Confirm**.
3. If the authority does not say what we claim, fix the entry — do not weaken the claim to fit.
4. Sign the whole group off in one command, recording what you actually read:

   ```sh
   npm run audit:status                     # where things stand
   npm run audit:verify -- --group "<authority>" --evidence "<reporter and page, or URL>"
   npm run audit:verify -- --group "<authority>" --evidence "..." --apply
   ```

   It is dry by default, refuses to run without evidence, and stamps the evidence onto every
   entry in the group. Editing the JSON by hand works too, but an authority backs up to 17
   entries and that is 17 chances to set the flag on the wrong one.
5. Re-run `npm run validate:corpus` (it rejects `verified: true` without the status) and `npm run audit:citations`.
